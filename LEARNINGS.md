# Learnings

- **Visual proof captured transition and stacked toasts (2026-08-15):** New lesson screenshots were taken immediately after render while the 300 ms step animation was still near zero opacity, and the machine report shot retained phase/flag toasts. Remedy: make the shared screenshot helper wait beyond UI transitions and wait for 2.6-second toasts to expire before capturing stable report states.

- **Machine autonomy repaint lost terminal focus (2026-08-15):** Switching Assisted/Guided repainted only the phase panel, leaving focus on the removed autonomy button while the persistent terminal input stayed unfocused. Remedy: after a mode change and panel repaint, explicitly call the terminal's public focus method so keyboard users can continue immediately.

- **E2E visual probe bypassed the new semantic sequence (2026-08-15):** A later handshake-image assertion still expected one click from lesson entry to the diagram, but the pilot now begins with required diagnosis, prediction, and worked example. Remedy: update every direct entry into a migrated lesson to complete its evidence steps before asserting downstream visuals; search for all references to the pilot ID after changing its sequence.
- **E2E retained eliminated-choice feedback contract (2026-08-15):** The browser suite still required a wrong quiz option to become disabled and report the remaining count, contradicting the new corrective-retry design. Remedy: assert that the chosen option is marked incorrect but remains enabled, feedback names/explains the choice, and no elimination count appears.

- **Repeated raw-template delimiter collision in documentation (2026-08-15):** After documenting the placeholder remedy, a Markdown patch was still wrapped in `String.raw` while containing unneutralized code backticks, so it failed before `apply_patch`. Remedy: scan documentation patches for every backtick too; replace all with a neutral marker before constructing the raw string, then restore immediately before application.

- **Concept skill collapsed into command alias (2026-08-15):** The mastery reachability pass added the conceptual `python` skill, but `habilidadesDeEjercicio` applied command aliases to explicit pedagogy labels and converted it to `python3`, leaving the capability unreachable. Remedy: preserve explicit/transversal catalog IDs verbatim and apply aliases only to commands inferred from code or inline examples.

- **Pedagogy patch template interpolation (2026-08-15):** A large add/update patch embedded target JavaScript template literals inside the orchestrator's `String.raw`, so `${...}` was evaluated before `apply_patch` ran. Remedy: neutralize both target backticks and `${` openers with placeholders, construct the raw patch, then restore the placeholders immediately before applying it.

- **Repeated positional wildcard during pedagogical implementation (2026-08-15):** A permissions-content search passed `js/data/modulos-*.js` as a positional Windows path even though this failure mode was already documented. Remedy: always search `js/data` and constrain module filenames with `-g 'modulos-*.js'`; never pass a wildcard as a Windows path.

- **Lesson visual probe serialized an entire room (2026-08-15):** A query meant to inspect one representative task embedded `SALA_POR_ID[t.salaId]`, which expanded all seven lessons and their exercises into a large output. Remedy: project only room metadata (`id`, `nombre`, task IDs/titles) and the selected task fields; never stringify a complete room for a single-lesson capture.

- **Visual proof script projected away a running session ID (2026-08-15):** A long Playwright capture returned an ongoing exec session, but the wrapper printed only `exit_code` and `output`, losing the `session_id` needed to resume or stop it. Remedy: print/store the complete exec result whenever a command can exceed the yield window, or keep each capture batch below the timeout.
- **Lesson view hides global navigation (2026-08-15):** A visual capture tried to click the global Máquinas tab while still inside the full-screen lesson player, so the script waited until timeout after producing only three screenshots. Remedy: leave with `.leccion-salir` or navigate directly through `window.__mentor.ir(...)` before targeting global tabs; capture independent views in short batches.

- **Audit aggregation overwrote repeated origins (2026-08-15):** A diagnostic assigned one summary per `sala.origen`, so later rooms replaced earlier rooms and understated task totals. Remedy: group rooms first or append tasks/exercises into per-origin arrays before calculating distributions; sanity-check grouped subtotals against the global 311/1,547 totals.

- **Repeated positional wildcard in test audit (2026-08-14):** The audit passed `tests\\*.mjs` and `tests\\*.js` as positional Windows paths even though this failure mode was already documented. Remedy: always search the directory and constrain filenames with `-g '*.mjs' -g '*.js'`; copy this exact stable form into future audit commands.

- **Repeated dependency manifest assumption during audit (2026-08-14):** A grouped repository audit requested `package.json` even though the existing learnings already document that this static PWA has no dependency manifest. Remedy: begin audits with `rg --files -g 'package.json' -g 'manifest.webmanifest'` and only read paths returned by discovery; use the test scripts directly for verification.

- **PowerShell Syntax/Literal Paths (2026-08-06):** A combined discovery call failed because `rg` returns exit code 1 when no `AGENTS.md` or `LEARNINGS.md` match exists. Remedy: treat an empty `rg --files` result as expected and run independent inspection commands so one empty search does not hide other output.
- **Git shallow branch tracking (2026-08-06):** A branch fetched into a `--single-branch` clone was not accepted as a trackable remote branch. Remedy: create the local branch from the verified commit SHA, then configure its upstream only after the remote fetch ref is present in the clone configuration.
- **Incorrect hypothesis / binary fixtures (2026-08-06):** A valid NUL-prefixed fixture was initially blamed when `file` reported ASCII; inspection showed that the command only recognized scripts, empty files, and text. Remedy: inspect both fixture bytes and command classification logic, then add explicit ELF/binary signature handling.
- **CLI nested-option parsing (2026-08-06):** `sudo` consumed a nested command's `-i` option, while Netcat treated any argument containing `l` as listen mode. Remedy: enter a root shell before `chattr -i` and match Netcat flags explicitly.
- **Content/fixture parity (2026-08-06):** A Wargame objective required two Base64 decoding layers while its fixture still held plaintext. Remedy: execute every published solution against its dedicated clean snapshot and require the expected secret in the final output.
- **Machine gate parity (2026-08-06):** Machine recon checks over-escaped target IPs and SUID scenarios referenced a binary without its SUID bit. Remedy: validate complete phase sequences, use a direct escaped-IP regex, and encode each advertised weakness in its snapshot.
- **Patch context and Unicode (2026-08-06):** Broad patches failed when terminal rendering and source Unicode produced different visible context. Remedy: inspect exact nearby source, patch the smallest stable ASCII-delimited region, and verify the resulting module through Node rather than trusting console glyph rendering.
- **Manifest filename assumption (2026-08-06):** A grouped inspection asked for `manifest.json`, but this PWA uses `manifest.webmanifest`, causing an avoidable failed command. Remedy: discover exact filenames with `rg --files` before opening optional project artifacts.
- **Normalized IDs and fixture paths (2026-08-06):** New block mappings and lab checks assumed planned slugs and `/opt` paths instead of the IDs and home-relative files actually produced by legacy normalization. Remedy: enumerate normalized IDs and snapshot files from the running data model, then make route maps and test commands use those exact values.
- **Hidden mobile overflow (2026-08-06):** The document reported no horizontal overflow while a long `<pre>` expanded a nested CSS grid to 838px and the parent silently clipped exercise text. Remedy: inspect client widths inside each component, use `minmax(0,1fr)` plus `min-width:0`, and verify the exact content cards at 390px rather than relying only on document scroll width.
- **Browser QA tool mismatches (2026-08-06):** The local browser backend rejected `networkidle` despite the generic API reference, and one probe contained patch-style `+` prefixes. Remedy: use `domcontentloaded` for this backend and syntax-check small evaluation snippets before sending them.
- **Mobile command submission (2026-08-06):** Automated mobile keypresses did not submit the terminal form even though the input retained focus and text. Remedy: keep Enter support but add an explicit, accessible submit button beside the prompt; this also gives touch users a reliable visible action.
- **E2E route selector (2026-08-06):** The test assumed the Continue CTA would point to the first terminal exercise, but it correctly points to the first unfinished quiz. Remedy: enter the room through its unique room card, then target the terminal exercise explicitly inside the room.
- **Machine session reconstruction (2026-08-06):** Completed phase IDs persisted, but recreating a machine terminal discarded the enumerated access gate and target/root shell state; newly rendered hint buttons also lost listeners. Remedy: rebuild shell identity and access flags from saved phases and delegate phase-hint clicks from the stable phase container.
- **PowerShell pipeline exit propagation (2026-08-06):** A combined audit returned useful output but surfaced exit code 1 because a piped search command controlled the script status. Remedy: capture `rg` output separately or finish mixed read-only audit scripts with an explicit successful expression when empty/partial matches are acceptable.
- **In-app browser tab association (2026-08-06):** A newly created local QA tab immediately reported that it was not part of the selected browser session. Remedy: keep the valid browser binding, discard only the stale tab handle, create a fresh tab, and use the documented non-Playwright surface if the injected helper remains unavailable.
- **PowerShell mixed-quote search (2026-08-06):** A quick `rg` probe combined single-quoted patterns with an unmatched double quote and failed before searching. Remedy: use one quoting style per PowerShell argument and split unrelated patterns into separate probes when source text contains both quote types.
- **Stale PWA origin during QA (2026-08-06):** Port 8123 kept serving the previous shell through its registered service worker, which made the redesigned app look unchanged. Remedy: use a fresh local origin for each major PWA visual pass and verify the document title plus cache version before trusting screenshots.
- **Optional Git config probe (2026-08-06):** A pre-push audit ended with exit code 1 because unset `user.name` or `user.email` was queried as a required command after otherwise successful checks. Remedy: inspect optional Git config with `--get` plus explicit fallback, then derive repository-local identity only from verified project history or user input.
- **Repeated PowerShell regex quoting (2026-08-09):** A compound audit appended an `rg` pattern containing escaped double quotes after a valid read; PowerShell split the expression and treated part of it as a module name. Remedy: keep `rg` patterns single-quoted in PowerShell and run source reads plus regex probes as separate commands when either contains nested quotes.
- **Visual cohesion is not visual repetition (2026-08-09):** The first cover batch reused the same isometric enamel material, centered composition, and miniature-diorama language across every section, so the subjects changed but the experience did not. Remedy: keep cohesion through palette, lighting, crop, and color grade while deliberately varying medium, viewpoint, character, scale, and story; review the full contact sheet for diversity before integrating assets.
- **Dependency manifest assumption (2026-08-09):** A source inspection also requested `package.json`, but this dependency-free static PWA does not have one, turning a successful artwork read into a failed grouped command. Remedy: discover manifests before grouped reads and reuse the runtime fallback already encoded in `tests/e2e.mjs` for Playwright tooling.
- **E2E visual-contract drift (2026-08-09):** After promoting Wargame from a collapsed counter to the requested illustrated card panel, one test still required four folded sections. Remedy: when a deliberate UI change replaces an interaction model, update the E2E assertion to protect the new visible contract while retaining checks for the auxiliary sections that should remain collapsed.
- **Generated deliverable is not integrated UI (2026-08-09):** The approved eight content covers existed in `outputs/portadas-nuevas`, but only the later machine and Wargame card art had been connected to the app. Remedy: distinguish clearly between exported artwork and integrated assets; copy approved files into the repository, reference them from the renderer and service worker, and assert the real PNG sources in E2E before calling the redesign complete.
- **PowerShell deployment probe variables (2026-08-09):** A public-site check first interpolated `$base?` without braces and then used `$home`, which collides case-insensitively with PowerShell's read-only `$HOME`. Remedy: delimit variables next to URL punctuation as `${sitioBase}` and use task-specific names such as `$respuestaInicio`; never reuse system variable names.
- **Compound audit output overflow (2026-08-10):** A broad grouped `rg` audit mixed several large source probes, exceeded the useful output budget, and surfaced a nonzero pipeline status despite returning partial evidence. Remedy: inspect one concern at a time with exact files, narrow patterns, and bounded line ranges; derive inventories by importing the data model instead of dumping source matches.
- **Inline Node quoting during shell audit (2026-08-10):** A tilde test matrix embedded mixed single and double quotes inside PowerShell and `node -e`, corrupting the JavaScript before execution. Remedy: put quote-sensitive diagnostic code in a temporary `.mjs` file via `apply_patch`, execute it directly, and keep the production tree untouched.
- **PNG metadata dependency assumption (2026-08-10):** A visual inventory assumed `System.Drawing.Image` was available in PowerShell; the type was absent and emitted repeated errors. Remedy: read PNG IHDR width and height directly from file bytes or use the bundled document/image runtime only when visual rendering is required.
- **Repeated optional-probe masking (2026-08-10):** A parallel E2E preflight again let an empty optional port query return nonzero and suppress the successful source read, repeating the existing optional-probe pitfall. Remedy: never group optional state probes with required reads; give each probe an explicit fallback/result object and verify its exit semantics independently.
- **Broad curriculum keyword dump (2026-08-10):** A multi-pattern `rg` curriculum audit emitted a very large first group and exited before later capability groups were useful. Remedy: compute per-topic counts with quiet/count-only probes and request at most a few representative matches only after a gap is identified.
- **Cross-language backtick collision (2026-08-10):** A PowerShell newline escape inside a JavaScript template literal closed the orchestrator string before the command ran. Remedy: avoid backticks entirely in nested PowerShell commands; use `[Environment]::NewLine` or a temporary script for multi-language probes.
- **Ripgrep globs on Windows (2026-08-10):** Passing `js\\data\\salas-*.js` as a positional path made ripgrep hand an invalid wildcard path to Windows after returning useful matches from other files. Remedy: pass the directory as the path and constrain filenames with `-g 'salas-*.js'`, or enumerate exact files with `rg --files` first.
- **Regex quoting regression during tilde audit (2026-08-10):** A compound `rg` expression mixed escaped double quotes with PowerShell quoting and reached ripgrep as an unclosed group, repeating a documented pitfall. Remedy: for literal shell tokens use separate fixed-string expressions (`rg -F -e 'cd ~' -e '~/'`) and never build a regex around mixed quote characters in PowerShell.
- **PowerShell foreach pipeline parsing (2026-08-10):** Piping directly from a statement-level `foreach (...) { ... }` produced an empty-pipeline parser error. Remedy: assign the loop output to a task-specific array first, then pipe that array to formatting or aggregation commands.
- **Repeated positional wildcard after documented fix (2026-08-10):** A later audit command again passed `refuerzos-*.js` as a Windows path instead of a ripgrep glob, proving the first remedy was not applied consistently. Remedy: use the stable form `rg ... js/data -g 'refuerzos-*.js'` every time; never place `*` in a positional Windows path.
- **Lazy image decode timing in E2E (2026-08-10):** Pedagogical PNG elements were visible before `loading="lazy"` had populated `naturalWidth`, so three immediate assertions failed even though the UI and console were healthy. Remedy: scroll the target into view and wait explicitly for `complete && naturalWidth > 0` before checking dimensions or offline availability.
- **Optional stopped-process verification (2026-08-10):** The temporary E2E server stopped correctly, but a following `Get-Process` lookup returned the script's final exit code 1 because the process was intentionally absent. Remedy: assign the optional lookup with `-ErrorAction SilentlyContinue` and emit an explicit success result for both the present and absent branches.
- **README tree patch context (2026-08-10):** A grouped documentation patch assumed a `salas-defensa.js` line that the README tree does not contain, so the whole patch was rejected. Remedy: inspect the exact bounded README sections first and patch independent stable lines instead of anchoring unrelated edits to an assumed inventory entry.
- **Parallel read wrapper omission (2026-08-10):** Two planned curriculum reads were inserted into a parallel call list as plain command strings instead of `shell_command` promises, so the orchestrator printed them without executing them. - **Snapshot literal probe pipeline (2026-08-10):** A fixed-string snapshot search used speculative source text and piped its empty result into `Select-Object`, surfacing exit code 1. - **Phase 3 entry-route contract drift (2026-08-10):** The curriculum correctly promoted `fundamentos-informatica` ahead of `linux-cero`, but a Phase 2 assertion still required `linux-cero` to have no prerequisites.
