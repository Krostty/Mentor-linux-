# Learnings

- **PowerShell Syntax/Literal Paths (2026-08-06):** A combined discovery call failed because `rg` returns exit code 1 when no `AGENTS.md` or `LEARNINGS.md` match exists. Remedy: treat an empty `rg --files` result as expected and run independent inspection commands so one empty search does not hide other output.
- **Git shallow branch tracking (2026-08-06):** A branch fetched into a `--single-branch` clone was not accepted as a trackable remote branch. Remedy: create the local branch from the verified commit SHA, then configure its upstream only after the remote fetch ref is present in the clone configuration.
- **Incorrect hypothesis / binary fixtures (2026-08-06):** A valid NUL-prefixed fixture was initially blamed when `file` reported ASCII; inspection showed that the command only recognized scripts, empty files, and text. Remedy: inspect both fixture bytes and command classification logic, then add explicit ELF/binary signature handling.
- **CLI nested-option parsing (2026-08-06):** `sudo` consumed a nested command's `-i` option, while Netcat treated any argument containing `l` as listen mode. Remedy: enter a root shell before `chattr -i` and match Netcat flags explicitly.
- **Content/fixture parity (2026-08-06):** A Wargame objective required two Base64 decoding layers while its fixture still held plaintext. Remedy: execute every published solution against its dedicated clean snapshot and require the expected secret in the final output.
- **Machine gate parity (2026-08-06):** Machine recon checks over-escaped target IPs and SUID scenarios referenced a binary without its SUID bit. Remedy: validate complete phase sequences, use a direct escaped-IP regex, and encode each advertised weakness in its snapshot.
- **Patch context and Unicode (2026-08-06):** Broad patches failed when terminal rendering and source Unicode produced different visible context. Remedy: inspect exact nearby source, patch the smallest stable ASCII-delimited region, and verify the resulting module through Node rather than trusting console glyph rendering.
- **Manifest filename assumption (2026-08-06):** A grouped inspection asked for `manifest.json`, but this PWA uses `manifest.webmanifest`, causing an avoidable failed command. Remedy: discover exact filenames with `rg --files` before opening optional project artifacts.
- **Normalized IDs and fixture paths (2026-08-06):** New block mappings and lab checks assumed planned slugs and `/opt` paths instead of the IDs and home-relative files actually produced by legacy normalization. Remedy: enumerate normalized IDs and snapshot files from the running data model, then make route maps and test commands use those exact values.
- **Hidden mobile overflow (2026-08-06):** The document reported no horizontal overflow while a long `<pre>` expanded a nested CSS grid to 838px and the parent silently clipped exercise text. Remedy: inspect client widths inside each component, use `minmax(0,1fr)` plus `min-width:0`, and verify the exact content cards at 390px rather than relying only on document scroll width.
- **Browser QA tool mismatches (2026-08-06):** The local browser backend rejected `networkidle` despite the generic API reference, and one probe contained patch-style `+` prefixes. Remedy: use `domcontentloaded` for this backend and syntax-check small evaluation snippets before sending them.
- **Mobile command submission (2026-08-06):** Automated mobile keypresses did not submit the terminal form even though the input retained focus and text. Remedy: keep Enter support but add an explicit, accessible submit button beside the prompt; this also gives touch users a reliable visible action.
- **E2E route selector (2026-08-06):** The test assumed the Continue CTA would point to the first terminal exercise, but it correctly points to the first unfinished quiz. Remedy: enter the room through its unique room card, then target the terminal exercise explicitly inside the room.
- **Machine session reconstruction (2026-08-06):** Completed phase IDs persisted, but recreating a machine terminal discarded the enumerated access gate and target/root shell state; newly rendered hint buttons also lost listeners. Remedy: rebuild shell identity and access flags from saved phases and delegate phase-hint clicks from the stable phase container.
- **PowerShell pipeline exit propagation (2026-08-06):** A combined audit returned useful output but surfaced exit code 1 because a piped search command controlled the script status. Remedy: capture `rg` output separately or finish mixed read-only audit scripts with an explicit successful expression when empty/partial matches are acceptable.
- **In-app browser tab association (2026-08-06):** A newly created local QA tab immediately reported that it was not part of the selected browser session. Remedy: keep the valid browser binding, discard only the stale tab handle, create a fresh tab, and use the documented non-Playwright surface if the injected helper remains unavailable.
- **PowerShell mixed-quote search (2026-08-06):** A quick `rg` probe combined single-quoted patterns with an unmatched double quote and failed before searching. Remedy: use one quoting style per PowerShell argument and split unrelated patterns into separate probes when source text contains both quote types.
- **Stale PWA origin during QA (2026-08-06):** Port 8123 kept serving the previous shell through its registered service worker, which made the redesigned app look unchanged. Remedy: use a fresh local origin for each major PWA visual pass and verify the document title plus cache version before trusting screenshots.
- **Optional Git config probe (2026-08-06):** A pre-push audit ended with exit code 1 because unset `user.name` or `user.email` was queried as a required command after otherwise successful checks. Remedy: inspect optional Git config with `--get` plus explicit fallback, then derive repository-local identity only from verified project history or user input.
- **Ámbito de bloque en Python (2026-08-08):** el intérprete nuevo creaba un entorno por cada `if`/`for`/`while`, así que `total += i` dentro de un bucle se perdía en cada vuelta y un `while` se volvía infinito. Remedio: en Python solo las funciones abren ámbito (en Lua sí lo abren los bloques), y la asignación liga siempre en el ámbito actual.
- **Indentación y tokenizador (2026-08-08):** al emitir INDENT/DEDENT se olvidó marcar la línea como ya procesada, y el tokenizador volvía a medir la sangría del mismo punto en bucle. Remedio: salir del estado «inicio de línea» antes de emitir el token, y probar cada construcción del lenguaje suelta antes de armar guiones largos.
- **Enteros y decimales (2026-08-08):** representar los números solo con `number` de JavaScript hacía que `10 / 2` imprimiera `5` cuando Python y Lua imprimen `5.0`, es decir, enseñaba algo falso justo en la lección que explica `/` frente a `//`. Remedio: envolver los decimales en un tipo propio y desenvolverlos en los pocos puntos que miran el valor crudo.
- **Soluciones de terminal multilínea (2026-08-08):** las pruebas de contenido parten `solucion` por saltos de línea y ejecutan cada trozo como una orden, así que un `python3 -c` con varias líneas se rompía en dos comandos inválidos. Remedio: cada línea de una solución tiene que ser una orden de shell completa; para el código de varias líneas, `printf '%s\n' ... > archivo` y después ejecutar.
- **printf sin reutilizar el formato (2026-08-08):** el `printf` simulado consumía solo el primer argumento, de modo que `printf '%s\n' uno dos tres` escribía una línea en vez de tres; se descubrió al escribir archivos de varias líneas desde una lección. Remedio: repetir el formato hasta agotar los argumentos, como el `printf` real.
- **Ejecutar por ruta (2026-08-08):** la shell buscaba todo comando en su tabla, así que `./script.sh` respondía `command not found` y no había forma de enseñar `chmod +x` más shebang. Remedio: si el nombre lleva barra, resolverlo en el filesystem, comprobar el permiso de ejecución y elegir intérprete leyendo la línea `#!`.
- **Peso de las portadas rasterizadas (2026-08-08):** los degradados suaves hacen que un PNG de 1200×600 pese ~200 KB, y 29 combinaciones de escena y color sumaban casi 6 MB de precaché. Remedio: rasterizar solo las portadas grandes (10) a 800×400 y dejar en SVG las tarjetas pequeñas, donde la diferencia no se aprecia.
